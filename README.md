# energy-planner

Метод і веб-сервіс планування енергоспоживання домогосподарства в умовах невизначеності графіків відключень електроенергії (магістерська робота).

Користувач вводить графік відключень, побутові прилади й параметри зарядної станції, а сервіс складає план на добу: коли вмикати прилади, щоб вони відпрацювали навіть тоді, коли відключення почнеться раніше чи закінчиться пізніше за графік.

## Структура

| Тека | Що там |
|---|---|
| `core/` | Модель задачі, імітація доби, генератор сценаріїв, алгоритми, тести й експерименти |
| `server/` | API на Express і PostgreSQL: планування, облікові записи, кабінет (див. `server/README.md`) |
| `client/` | Сайт на React + Vite |
| `docs/model.md` | Опис математичної моделі та методу |

## Запуск

Потрібен Node.js 20.19 або новіший.

```bash
npm install
npm run dev:server   # API на http://localhost:3001
npm run dev:client   # сайт на http://localhost:5173
```

Для облікових записів потрібна PostgreSQL, як її підняти описано в `server/README.md`. Без неї працює сторінка плану без входу.

Продакшн-збірка: `npm run build`, після чого `node server/src/index.js` віддає і API, і сайт.

## Тести й експеримент

```bash
npm test              # тести ядра й API
npm run experiment    # порівняння методів, результати в core/experiments/results/
```
