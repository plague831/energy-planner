# Набір даних: зміни графіків відключень YASNO

Мета: виміряти, наскільки реальні графіки відключень відрізняються від опублікованих і як часто оператор їх змінює, щоб налаштувати модель невизначеності планувальника на реальних даних, а не на припущеннях.

## Як збираються дані

- `collect.js` завантажує графіки всіх регіонів YASNO (зараз Київ і Дніпро, два оператори) з відкритого API.
- GitHub Actions (`.github/workflows/collect-yasno.yml`) запускає його кожні 30 хвилин. Знімок зберігається лише тоді, коли графік змінився, тому кожен файл відповідає одній зміні.
- Знімки лежать в окремій гілці `yasno-data` у теці `snapshots/<регіон>-<оператор>/<дата>/<час UTC>.json`.

Запустити вручну локально:

```bash
node research/yasno/collect.js /шлях/до/теки
```

## Формат знімка

```json
{
  "fetchedAt": "2026-10-15T09:33:00.000Z",
  "region": { "id": 25, "name": "Київ" },
  "dso": { "id": 902, "name": "ПРАТ «ДТЕК КИЇВСЬКІ ЕЛЕКТРОМЕРЕЖІ»" },
  "data": { "1.1": { "today": { "slots": [...], "date": "...", "status": "ScheduleApplies" }, "tomorrow": {...}, "updatedOn": "..." } }
}
```

`slots` — інтервали у хвилинах від початку доби, `type`: `Definite` (відключення) або `NotPlanned`. Статуси дня: `ScheduleApplies`, `NoOutages`, `WaitingForSchedule`, `EmergencyShutdowns`.

## Обмеження

- Інтервал 30 хвилин: зміни, які прожили менше, можуть бути пропущені. GitHub також може запускати розклад із затримкою.
- Фактичний час відключень YASNO не публікує, тому набір показує зміни графіка, а не точний момент, коли світло зникло.
